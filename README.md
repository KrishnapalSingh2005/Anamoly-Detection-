# 🔍 Anomaly Detection System

A machine learning project that detects anomalies (outliers) in datasets using statistical methods and unsupervised learning algorithms.

## 🚀 Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Outlier detection using Z-Score and IQR
- Machine learning models like Isolation Forest and LOF
- Data visualization of anomalies
- Result analysis and comparison

## 🛠️ Tech Stack
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

## 📌 Use Cases
Fraud detection, system monitoring, predictive maintenance, and data quality analysis.
